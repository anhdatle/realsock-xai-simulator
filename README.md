# Realsock XAI — Supply Chain-to-Housing Market Simulator

A static, mobile-ready research demonstration for tracing a supply-chain disruption through an Australian residential development project. The included case is a six-week Strait of Hormuz disruption scenario.

## Run locally

Open `explainable-ai-demo.html` in a browser. No build step, server, database, API key, account, or installation is required.

## Publish on GitHub Pages

1. Create a public GitHub repository and upload the contents of this folder.
2. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
3. Open the generated Pages URL. The root page redirects to the interactive demo.
4. In the deployed demo, select **Share / QR**. The generated QR opens the same public URL on a phone.

## Important scope

All project figures are explicitly illustrative scenario inputs for an A$80m apartment development. They show how an explainable decision workflow can operate; they are not verified forecasts, project quotes, or advice.

## Files

- `index.html` — GitHub Pages entry point
- `explainable-ai-demo.html` — standalone interactive demo
- `site.webmanifest` — mobile web-app metadata
